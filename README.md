# activity_project

Full-stack **web** app: Express + MySQL backend (`backend/`) and React + Vite frontend (`frontend/`).

The `mobile/` Expo app is intentionally not included in this repository.

## Scripts (from repo root)

- `npm run install-all` — install backend and frontend dependencies
- `npm run backend` — start API
- `npm run frontend` — start Vite dev server

Configure environment variables for the backend (see `backend/.env` example if present) before running in production.
